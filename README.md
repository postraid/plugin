# Postraid plugin

Browse your Postraid brands and saved social content, then save supplied slide copy as editable carousel drafts. Review in Postraid before publishing; no generation, scheduling or credit spending.

## Connect

Install this repository as a Claude Code plugin, then authorize Postraid in your browser. The remote MCP endpoint is https://mcp.postraid.com/mcp. No API key is required.

## Workflows

- Find the brands in your own workspace.
- Browse saved content and inspect a post before writing new copy.
- Save a title, up to ten slides and hashtags as an editable carousel draft.

The MCP cannot generate images or video, spend credits, schedule or publish posts, access social credentials, or read another customer’s workspace. Existing profile-only connections must reconnect to grant content access.

## Example prompts

“List my Postraid brands and show the latest saved posts.”

“Save this supplied copy as a carousel draft without publishing it.”
